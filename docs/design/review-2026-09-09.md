# Chatty design review — 2026-09-09

The interface has a coherent identity: navy/lavender, yellow actions, rounded conversation
surfaces and a small expressive character. The refinement should make that character feel
present throughout the product while protecting reading, navigation and clear feedback.

## Decisions made in this review

| Surface | Finding | Result |
| --- | --- | --- |
| Login introduction | The independent letter landings, held glances and greeting already provide a distinctive entrance. | Retained the character sequence, skip/Escape, reload replay and reduced-motion bypass. |
| Chat welcome | A generic messaging icon disconnected the quiet welcome from the character introduced at login. | Reused the actual Chatty face, with its existing gaze/blink behavior, inside the compact welcome. |
| Sidebar | The yellow “Let’s talk” pill looked interactive but was a decorative span. | Made it a keyboard-accessible button that focuses people search. |
| Validation | Uppercase mono errors felt mechanical; the surface styling could obscure invalid-field borders. | Sentence-case error text, explicit error borders/focus treatment, and announced server errors. |
| Message rhythm | The real wrapped-text regression measured a two-line bubble at 61.375px, beyond the intended compact height. | Reduced vertical bubble padding from 9px to 8px while preserving content, wrapping and navigation. |
| Theme picker | Interpolating border/shadow briefly left the previous selection looking active. | Selection updates immediately; only color/hover feedback transitions. |
| Settings typography | Heavy display headings competed with the practical form content. | Matched headings to the calmer semibold interface type used in authentication. |
| Small-screen settings | The main settings column lacked a zero minimum height inside its bounded modal. | Allowed that column to shrink so the inner content scrolls and actions stay reachable. |
| Action feedback | Main actions and the welcome CTA could respond more clearly to a press. | Added a 1px primary-button press and a small CTA-arrow movement, both disabled under reduced motion. |

## Motion direction

The entrance is expressive. Actions respond briefly. Reading surfaces stay still. The mascot's
movement is bounded and returns to rest; chat rows and messages do not gain decorative looping
motion. This keeps the personality recognizable without making every element compete for attention.

## Review and verification

The initial browser review exercised entry layouts, appearance persistence, button/focus affordances,
shared theme preview/sync/reset, attachments, pins and wrapped group messages. It found the bubble
height regression described above; the other 16 scenarios passed.

Follow-up checks cover the corrected wrapped text, invalid-field color while focused in both themes,
the two search entry points, small-screen settings reachability, theme selection and entry layouts.
All nine follow-up scenarios passed across the targeted reruns. The production build, typechecks,
lint, formatting, 70 related unit tests and rules audit passed.

Screenshots were reviewed for authentication and errors, the welcome, themes, attachment controls,
conversation text and settings. Browser fixtures use the isolated end-to-end database.

This is a Chromium review at desktop and emulated phone dimensions, including reduced motion and
light/dark palettes. It does not establish physical-device, Safari or complete assistive-technology
coverage. The design is ready for the owner's next hands-on review; aesthetic judgment remains
separate from passing automated checks.
